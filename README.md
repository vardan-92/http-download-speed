# Замер скорости скачивания по HTTP

Консольный скрипт делает 10 последовательных GET-запросов к заданному URL. Следующий запрос начинается после чтения всего тела предыдущего ответа.

## Запуск

Нужен Node.js 22 или новее. Установка зависимостей не требуется.

```sh
node speed-test.mjs "https://example.com/"
```

Для замера скорости подставьте прямую HTTP- или HTTPS-ссылку на достаточно большой файл. Маленькие ответы сильнее зависят от задержки первого байта.

## Результат

- Среднее время одного запроса в миллисекундах. Время измеряется от начала запроса до полного чтения ответа.
- Общий объём полученных тел ответа в байтах. При сжатии учитывается размер сжатого тела. Заголовки HTTP в объём не входят.
- Скорость в мегабитах в секунду (Мбит/с). Объём переводится в биты, делится на сумму времени запросов в секундах и на 1 000 000. Один мегабит равен 1 000 000 бит.

Результат зависит от выбранного сервера и включает сетевую задержку. При ошибке HTTP, обрыве ответа или превышении 30 секунд на запрос скрипт выводит ошибку и завершается с кодом 1.
